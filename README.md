# PenguinMod Extension Data

Extension data collected from multiple extension galleries, available as JSON for Scratch and PenguinMod projects.

|---|---|
| PenguinMod | [View JSON](https://penguinmodding.github.io/penguinmod-extensions.json) |

| Pooid7 | [View JSON](https://penguinmodding.github.io/pooid7.json) |

| Ruby Devs | [View JSON](https://penguinmodding.github.io/ruby-gallery.json) |

## JSON format

Each dataset is intended to contain:

- `names` - extension names
- `links` - extension source URLs
- `thumbnails` - thumbnail image URLs
- `newExtensions` - newly detected extensions
